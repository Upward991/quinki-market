# Data Analysis

1. **Understand the data** — schema, types, missing values.
2. **Clean** — nulls, duplicates, formats; document decisions.
3. **Explore** — distributions, correlations, outliers.
4. **Conclude** — answer with numbers, not just plots.

## Rules
- Run code for every claim.
- Save cleaned data and scripts.
