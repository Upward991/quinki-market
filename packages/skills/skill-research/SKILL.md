# Web Research

When asked to research a topic:

1. **Plan queries** — break the topic into 3-5 sub-questions.
2. **Gather sources** — for each sub-question, open 2-3 credible sources.
3. **Cross-check** — note agreements and contradictions.
4. **Summarize** — write the final answer with inline citations [1], [2] and a source list.

## Rules
- Prefer primary sources.
- If sources conflict, say so explicitly.
- Never invent citations.
